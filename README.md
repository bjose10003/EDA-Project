# EDA Project

A Python and Pandas project for Exploratory Data Analysis (EDA).

## Project Structure

- `data/raw/` - Original datasets
- `data/processed/` - Cleaned datasets
- `notebooks/` - Jupyter notebooks for analysis
- `src/` - Reusable Python code
- `images/` - Charts and visualizations

## EDA Workflow

1. Load and inspect data
2. Check data types and missing values
3. Check duplicates
4. Generate summary statistics
5. Perform univariate analysis
6. Perform bivariate analysis
7. Detect outliers
8. Analyze correlations
9. Create visualizations
10. Document key insights

## Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter
